# Java + Spring Backend Interview Preparation 🚀

## Goal

Become **interview-ready for Java Spring Boot Backend roles** by building a strong foundation in Core Java, Advanced Java, Spring Boot, Databases, Testing, and DevOps.

This repository is designed as a **living handbook** that grows chapter by chapter and serves as a long-term reference for interviews and real-world backend development.

---

# Learning Philosophy

This is **not** a collection of random notes.

Every chapter is written with the mindset of:

* Understanding concepts from first principles.
* Learning how Java works internally.
* Connecting theory to production systems.
* Relating every concept to Spring Boot applications.
* Preparing for real interview questions.

The objective is to understand **why**, not just **how**.
